## 📄 一、 核心配置参数表

在 `index.html` 文件中，搜 `const CFG` 或 `const P` 即可快速调整基础设定：

| 变量/对象名 | 所在区域 | 作用与修改建议 |
| :--- | :--- | :--- |
| `CFG.world` | `§0 CONFIG` | 山谷地图世界大小（单位：米）。修改可改变地图总轮廓。 |
| `CFG.sunElev` / `sunAzim` | `§0 CONFIG` | 太阳的高度角与方位角。改小 `sunElev`（如 5.0）可打造黄昏拉长阴影效果。 |
| `CFG.cloudDeck` | `§0 CONFIG` | 积云云层高度（默认 980米）。 |
| `P.skyZenith` 等 | `§0b PALETTE` | **天空与环境调色板**（sRGB 16进制色值）。改这里可以一键将场景变为“秋天”、“雪景”或“魔幻夜景”。 |
| `QUALITY` | `§0 CONFIG` | 4档画质预设（草地密度、阴影分辨率、Bloom等级）。可针对移动端调低参数。 |
| `WindSys.baseSpeed` | `§5 THE WIND` | 基础风速（单位：米/秒），影响草浪摆动与风声音效。 |

## ⚡ 二、 性能优化改动说明

本次为解决卡顿问题，在原文件基础上做了 3 处改动。如果你的设备性能较好，或者改完后觉得画面效果打了折扣，可以参考下面的“原值”随时改回去；也可以根据自己的设备情况，在原值和当前值之间自行取一个折中数字。

### 改动 1：默认画质档位

**位置**：`const State = { q: ... }` 附近

```js
// 改动前（原值，默认高画质）
q: QS.has('q') ? clamp(+QS.get('q'),0,3) : 2,

// 改动后（当前，默认中画质）
q: QS.has('q') ? clamp(+QS.get('q'),0,3) : 1,

```

* **说明**：这个数字对应 `QUALITY` 数组的下标（`0`=低，`1`=中，`2`=高，`3`=极高）。它一次性控制了渲染分辨率倍数、草密度、阴影贴图分辨率、Bloom 层数、风场分辨率等一整套参数，是影响性能最大的一项。
* **影响**：全屏每一帧的渲染开销都会降低，是最“稳赚不赔”的一处改动，牺牲的画面细节也最不明显。
* **如何调整**：
* 想要更流畅：改成 `0`
* 想要更精细：改回 `2`（原值）或 `3`
* 也可以不改代码，直接在网址后面加 `?q=0`～`?q=3` 临时测试（如：`你的文件.html?q=3`），无需每次都改源码。



---

### 改动 2：自动降画质的等待时间

**位置**：`function frame(now)` 函数末尾

```js
// 改动前（原值，约 4~8 秒后才开始自动检测帧率）
if(++warmed === 260) autoQuality();

// 改动后（当前，约 1.5~3 秒后开始检测）
if(++warmed === 90) autoQuality();

```

* **说明**：程序会在运行一段时间后自动检测帧率，如果太低会自动帮你降一档画质（`autoQuality()` 函数）。原来等待 260 帧才检测，这段时间用户已经感受到卡顿了；改成 90 帧后，自动降档介入得更快。
* **影响**：不影响画面本身，只是让“卡了会自动变流畅”这件事发生得更早。如果你的设备一直很稳定，这一项基本感觉不到区别。
* **如何调整**：
* 数字越小，自动降档越快介入（但可能因开场加载未稳定而误判）；
* 数字越大，越接近原本“多等等再判断”的保守策略；
* 如果你不想要自动降画质功能，可以把 `State.autoQ` 相关逻辑关掉，或将此数字改成一个很大值（如 `999999`）。



---

### 改动 3：水面反射的触发距离

**位置**：`function riverOnScreen(fr, cp)` 函数内

```js
// 改动前（原值，380 米内的河面才触发反射）
if(cp && s.center.distanceToSquared(cp) > 380*380) continue;

// 改动后（当前，180 米内的河面才触发反射）
if(cp && s.center.distanceToSquared(cp) > 180*180) continue;

```

* **说明**：水面反射（`reflectionPass()`）本质上是将整个场景（地形、桥、树、村庄）从水面镜像视角**再完整渲染一遍**，代价接近渲染两倍的场景。这个数字决定“河面在多远的距离内才值得触发这次额外渲染”。
* **影响**：站在桥上、河边等近距离看水面时效果不变（依然有完整反射）；远眺河流时，反射会被跳过，改用天色代替（代码里 `skyDomeLite` 兜底），这种情况下反射本来也看不清细节，视觉损失极小。
* **如何调整**：
* 想要反射范围更大（接近原效果，但开销增加）：改回 `380` 或调至中间值（如 `250`）；
* 想要更流畅：可再调小（如 `120`）；
* 数字改的是“米数”（即 `距离*距离` 里的“距离”），修改时保证两处数字一致（如均改为 `250*250`）。



---

### 💡 性能调整小结（改动优先级）

1. **改动 1（画质档位）** —— 收益最大，改一处影响全场景，优先调这个
2. **改动 3（反射距离）** —— 如果场景里河流/水面出镜多，这个也很关键
3. **改动 2（自动降档等待时间）** —— 锦上添花，不改也不影响画面本身

*建议先只调改动 1 试一遍效果，觉得还不够流畅，再依次加上改动 3、改动 2。*
